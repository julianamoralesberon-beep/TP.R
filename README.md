# Trabajo Práctico de R - Laboratorio para el Análisis de Datos

Este repositorio contiene la resolución del trabajo práctico en **R** correspondiente a la materia **Laboratorio para el Análisis de Datos** de la **Universidad Torcuato Di Tella (UTDT)**.

## Descripción del Proyecto
El objetivo principal de este trabajo práctico es poner en práctica diversas herramientas, librerías y técnicas del lenguaje R mediante el **análisis exploratorio y la simulación de datos**. Los ejercicios abarcan distintas problemáticas estadísticas y computacionales evaluadas en el marco de la cursada.

## Tecnologías y Herramientas Utilizadas
* **Lenguaje:** `R`
* **Entorno de desarrollo recomendado:** `RStudio`
* **Librerías comunes (según corresponda):** `tidyverse`, `ggplot2`, `dplyr`, entre otras.

## Cómo Ejecutar el Proyecto
1. Clona este repositorio en tu máquina local
2. Abre el proyecto en **RStudio**.
3. Asegúrate de tener instaladas las dependencias necesarias.
4. Ejecuta los scripts correspondientes.
